# LICENSE AND USAGE / 利用許諾と使用条件

## 1. このコーパスについて

DXF-Test-Corpus は、CAD処理系（DXF読込・変換・表示・寸法/ハッチ/ブロック等の
エンティティ処理）の開発・検証を目的としたテスト用DXF集である。

- **出典**: 合成生成（build_corpus.py / ezdxf）。実案件データは含まない。
- **匿名化**: 完了。固有の人物名・組織名・地名・座標系秘密情報は含まない。
  （大座標ファイルの X=100000/Y=50000 等は架空のローカル座標である）

## 2. 利用許諾

本コーパス（DXF・マニフェスト・生成スクリプト一式）は、以下の目的に限り
無償で利用できる。

- [x] 社内開発（パーサ・変換器・ビューアの実装・デバッグ）
- [x] 回帰試験／自動テストへの組込み
- [x] 性能測定（大量エンティティ系ファイルの利用を含む）
- [x] 社外への成果物説明における「テストデータとしての」提示

### 禁止事項

- [ ] 本コーパスを「実測データ」として偽って販売・提供すること
- [ ] ファイル名のみ変更した複製を別の試験項目として計上すること
      （※受入試験のファイル数に数える際は、内容が異なるファイルのみ）

## 3. 公開可否

- **現状（合成コーパス）**: 公開可（MIT相応）。ただし実案件由来ファイルを
  追加した時点で、そのファイル群は本許諾の対象外とし、別途審査する。
- **実案件由来ファイル**: 公開可否は提供元と個別合意するまで「非公開」。
  匿名化済みであっても、公開前に提供元の承認を得ること。

## 4. 実案件受入用100件に必要な記録（チェックリスト）

実CADから出力する最終受入用コーパス（回帰20件＋業務受入80件）では、
manifest の以下の列を必ず埋めること。

| 項目 | 内容 |
|---|---|
| cad_name / cad_version | 出力元CADの名称とバージョン（例: AutoCAD 2025 / BricsCAD V24） |
| dxf_version | DXF出力バージョン（R12/R2000/R2018等。統一不要） |
| units / assumed_scale / paper_size | 単位・想定縮尺・用紙サイズ |
| encoding / fonts | 文字エンコーディング・使用フォント名 |
| reference_pdf | 正解PDF（レイアウト複数時は**全シート分**） |
| external_refs | 外部参照等の依存ファイル（フォント本体は再配布可能なもののみ） |
| anonymized | 匿名化の有無 |
| usage_license / publishable | 利用許諾・公開可否 |
| bucket | regression(20) / acceptance(80) |

### ファイル数の考え方

- 最終受入用: 実案件由来の**異なる**DXF 100件（回帰20＋受入80）。
  同じ図面の名前違いの複製は1件と数えない。
- 着手用: 寸法・ハッチ・ブロック・属性付きブロック各3件（計12件）で開始可。
- 本合成コーパス100件＋本READMEは**開発用**として別管理し、
  実案件100件には**加算しない**。
