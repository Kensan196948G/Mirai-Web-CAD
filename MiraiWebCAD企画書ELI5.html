01Mirai Web CADは何を作る計画？

パソコンのブラウザを開くだけで、土木工事の2D図面を正確に描ける、本格的なWeb CADを作る計画です。

線、円、文字、寸法などを自分で描ける普通のCAD機能をしっかり用意します。その上にAI Agentを載せて、「ここからここまで線を引いて」「この図面を会社のルールに合わせて」のようなお願いもできるようにします。

📐

正確な道具

定規、コンパス、分度器を一つにしたような2D CADです。

🌐

ブラウザで使う

専用パソコンだけでなく、Webブラウザから図面を開きます。

🤖

AIがお手伝い

作図の案を作り、直し方や間違いを教えてくれます。

紙の上で使う「定規と鉛筆」を、パソコンの中へ入れます。さらに、横で作業を手伝ってくれるAIも付けます。

02どうして作るの？

今のCAD作業では、人が線を一本ずつ引き、文字や寸法を入力し、同じような図面を何度も作ることがあります。図面のルールを覚えるのも大変です。

今の困りごとMirai Web CADで目指すこと
同じような線を何度も描くAIやTemplateでまとめて作る
Layerや文字の決まりを忘れる会社のルールを自動確認する
図面を開くために専用Softwareが必要Webブラウザで開いて確認する
修正箇所が分かりにくい変更前と変更後を色分けする
数量を別の表へ書き写す図形から長さや面積を集計する
人を減らすことが目的ではありません。人が「線を描く作業」に使う時間を減らし、「この図面で安全に工事できるか」「現場に合っているか」を考える時間を増やします。

03そもそも2D CADって何？

CADは、コンピューターで図面を描くための道具です。2Dは「縦と横」の平らな図面です。平面図、断面図、施工ヤード図などがこれに当たります。

紙のお絵描きとの違い

  • 長さを正確に指定できる
  • 線同士をぴったりつなげられる
  • 縮尺を変えて印刷できる
  • 同じ部品を何度も使える
  • 間違えた操作を元に戻せる

Mirai Web CADが大事にすること

  • 正確に描ける
  • 速く操作できる
  • 大きな図面でも軽く動く
  • 他社のCADと図面を受け渡せる
  • きれいにPDF・印刷できる

04「AutoCAD／ARES Standardの80～90％代替」とは？

全部の機能をコピーする意味ではありません。会社で毎日よく使う2D CAD作業の80～90％を、Mirai Web CADだけで終わらせるという意味です。

CADには、めったに使わない特殊機能もたくさんあります。それらを最初から全部作ると、本当に必要な機能がいつまでも完成しません。そこで、実際に使われる回数と作業時間を調べ、よく使う機能から完成させます。

判定考え方
代替できた図面を開く、描く、直す、寸法を入れる、印刷するところまで、他のCADへ戻らず完了した
もう少し基本作業はできるが、一部の文字・線種・印刷設定を他CADで直した
未代替重要な機能や互換性が足りず、作業の多くを他CADで行った

100種類の遊びがある道具を全部まねるより、毎日使う80種類を、とても使いやすく作るイメージです。

05Agentic AIは何をするの？

普通のチャットAIは質問に答えるだけです。Agentic AIは、目的を聞き、仕事を小さく分け、必要な道具を選び、順番に作業し、最後に結果を確認します。

🧭

考える

何を描くのか、何が足りないのか、どの順番で進めるかを整理します。

🛠️

道具を使う

線、移動、複写、寸法などの正確なCAD Commandを呼び出します。

🔍

確認する

Layer、寸法、重複線、変更内容が正しいか、別のAgentが検査します。

AIが勝手にしないための約束

  • 分からない条件を想像で決めず、人へ質問します。
  • 図面を書き換える前に、変更案を色分けして見せます。
  • 人は「全部使う」「一部だけ使う」「使わない」を選べます。
  • 変更はUndoで元に戻せます。
  • 承認済み図面やLockされたLayerは勝手に変えません。
  • AIが止まっても、普通の2D CADとして使えます。
AIは魔法の鉛筆ではありません。正確な線を描くのはCAD Coreです。AIは「どの道具を、どの順番で使うか」を考える作業リーダーです。

06専門Skillsって何？

Skillは、AIに渡す「会社で承認された作業手順書」です。

AIが毎回自由に考えるだけでは、図面の作り方がばらばらになります。Skillには、使うLayer、文字の大きさ、図枠、作業手順、やってはいけないこと、確認方法をまとめます。

たとえば「図面お掃除Skill」

  1. 重なった線を探す
  2. とても短い不要線を探す
  3. つながっていない線を探す
  4. 消す候補を色分けする
  5. 人が選んだものだけ直す

たとえば「会社標準Skill」

  1. 図面の種類を確認する
  2. 正しい図枠を選ぶ
  3. 標準Layerへ整理する
  4. 文字・線種・線幅を確認する
  5. 違反を一覧で知らせる

Skillも勝手には公開しません

1
作成中 — 担当者が手順を書く
↓
2
確認 — CADに詳しい人が内容を見る
↓
3
テスト — 正常・間違い・意地悪な入力で試す
↓
4
承認・公開 — 合格した版だけ正式図面で使う
↓
5
更新・停止 — 古くなったSkillは新しい版へ替えるか止める

08どんな2D CAD機能を作るの？

グループできること
描く線、Polyline、円、円弧、四角形、多角形、楕円、点、Hatch
直す移動、Copy、回転、拡大縮小、Mirror、Offset、Trim、延長、Fillet、面取り
正確に合わせる端点、中点、中心、交点、垂線、接線へのSnap、座標・距離・角度入力
説明を書く文字、寸法、引出線、表、注記
整理するLayer、Block、属性、外部参照、Template、標準部品
測る距離、角度、座標、長さ、面積、図形数
紙へ出すModel／Paper空間、Viewport、縮尺、用紙、線幅、PDF、印刷Preview
受け渡すDWG、DXF、PDFを読み、編集し、再出力。変換差を確認
守る自動保存、Undo/Redo、版管理、Comment、Review、承認、監査履歴

09今回は何を作らないの？

何でも入れると、どれも中途半端になります。そこで、2D CADを強くするために範囲をはっきり決めます。

集中して作る

  • 本格的な2D作図・編集
  • 土木施工図に必要な標準機能
  • DWG/DXF/PDF互換
  • 速い操作と大規模図面性能
  • Agentic AI＋専門Skills

今回の対象外

  • 3D CAD
  • BIM/CIM Model作成
  • 構造計算
  • 写真のようなRendering
  • 機械・電気専用CAD
  • AIだけの無人承認

まず「とても良い2Dの道具箱」を完成させます。大きなロボットまで同時に作ろうとして、肝心の定規が曲がっていたら困ります。

10どんな順番で育てるの？

Phase 1
正確な線・円・座標、選択、保存、Undo/Redoを作る
Phase 2
移動、Copy、Trim、Layer、文字、寸法、Snapを作る
Phase 3
Block、Hatch、Layout、Viewport、PDF・印刷を作る
Phase 4
DWG/DXFを読み書きし、変換の違いを見つける
Phase 5
大きな図面でも軽く動くようにする
Phase 6
Agentic AIと承認済みSkillsをつなぐ
Phase 7
実際の施工図でAutoCAD／ARESの80～90％を代替できるか試す
順番が大切です：最初にAIだけを作るのではなく、先に正確で信頼できる2D CADを作ります。その土台ができてからAIを働かせます。

11最後に、ひとことで言うと

Mirai Web CADは、「人が一本ずつ全部描くCAD」から、「人が目的を伝え、AIと一緒に正確な2D図面を仕上げるCAD」へ変える計画です。

CADが担当

正確な座標、図形、寸法、保存、変換、印刷。

AI＋Skillsが担当

計画、作図案、修正案、標準化、検査、説明。

人が担当

条件の確定、技術判断、採用する変更の選択、最終承認。

?ことばのミニ辞典

2D CAD：平らな図面を正確に描くSoftware。

Agentic AI：答えるだけでなく、仕事を計画し、道具を使い、結果を確認するAI。

Skill：AIが会社の決まりどおりに作業するための、承認済み手順書。

CAD Core：線や円を正確に計算して描く、CADの心臓部分。

Layer：図面の線を種類ごとに分ける透明な紙のようなもの。

Block：何度も使えるようにまとめた図形部品。

Snap：線の端や真ん中へ、Cursorをぴったり合わせる機能。

DWG／DXF：ほかのCADと図面を受け渡すための代表的なFile形式。

Undo：直前の操作を元に戻すこと。
