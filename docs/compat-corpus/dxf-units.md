# DXF単位の保持・換算

2026-09-05。mm/mの単位保持を追加。

| 条件 | 動作 |
| --- | --- |
| INSUNITS=4/6、取込先が空 | mm/mを採用し、座標値はそのまま保持 |
| INSUNITS=4/6、既存図形あり | 取込先単位を維持。新規図形のみm→mmは1000倍、mm→mは0.001倍 |
| INSUNITSなし/0 | 取込先単位として解釈し、未指定である旨を警告。元の物理単位は認定しない |
| 上記以外のINSUNITS | 取込を拒否 |

換算対象は現在読込可能なLINE/CIRCLE/ARC/ELLIPSE/SPLINE/Polyline/TEXT(MTEXT正規化後を含む)の座標、半径・軸長、文字高さ。換算で非有限値になった場合は全体を拒否。寸法・ハッチ・ブロック・Viewportの読書は引き続き未対応で、従来の拒否ガードを維持する。

単位採用は`set_empty_drawing_unit`トランザクション。図形がある状態や未対応単位の指定を拒否し、既存の権限・承認後ロック・監査・永続化経路を使用する。Undo/Redoは図形の削除後・追加前に単位を復元する。DXF書出しは保持した図面単位からINSUNITSを出力。

図面JSONの単位指定も空図面への再取込時に保持する。同単位JSONの追加取込は従来どおり。異単位JSONの追加取込は、寸法Style・Block等の換算を保証できないため一括拒否する。単位を持たない旧JSONは取込先単位として扱う。

## 検証と制限

単体で空図面へのm採用・DXF再出力、双方向の換算・既存図形不変、文字高さ/半径、未指定・未対応単位、オーバーフロー、権限/承認ロック、JSON再取込を検証。desktop/mobileでUndo/Redo・再読込・異単位追加取込を検証する。

合成100件の限定往復は31件通過・69件拒否のまま。通過したm図面は単位もmとして保持される。これは全属性互換や寸法/印刷尺度の認定ではない。

既存R12サンプル7件はINSUNITSがないため、取込は可能だが単位警告が付く。警告ゼロを条件とする一括検証では不合格となる。元データに根拠のない単位を黙って補完したり、原本を書き換えたりはしない。提供READMEのmm指定を認定へ用いる場合は、将来の明示的な単位指定/受入メタデータ機能で扱う。
